Accessibility

“DARAWAT is for everyone.”

We want DARAWAT to be easy to understand, navigate, and use for as many people as possible. We are continuously working to improve the accessibility of our platform and provide a better experience for every member of our community in San Jose de Buenavista, Antique.

Accessibility Options

Our Commitment

Building an inclusive digital bridge for local producers and consumers.

DARAWAT aims to provide an inclusive digital experience where consumers and producers can discover local products, find local producers, search for information, use maps, contact producers, manage their accounts, and access Help Center information.

We are continuously working to improve the accessibility of DARAWAT to ensure these functions remain usable regardless of a person's abilities or preferred way of interacting with the website.

Accessibility Features

Core technical and design measures implemented across our platform.

👁️

Visual Accessibility

Designed with readable font sizes, clear typography, good contrast, clearly visible buttons, descriptive labels, and alternative text for meaningful images.

  • Important info never relies on color alone
  • Sufficient contrast ratios
⌨️

Keyboard Accessibility

Users can navigate important website functions seamlessly using a keyboard without requiring a mouse.

  • Full Tab navigation support
  • Enter and Space activation
  • Visible keyboard focus outlines
  • Logical navigation order
🔊

Screen Reader Support

Built with semantic HTML and accessible ARIA labels so screen readers accurately interpret headings, buttons, navigation, and forms.

  • Semantic landmarks (header, nav, main, footer)
  • Descriptive button & link labels
🖼️

Images & Alternative Text

Meaningful graphics include descriptive alternative text (e.g., alt="Local farmer displaying freshly harvested vegetables"), while decorative graphics use empty alt tags.

  • Contextual image descriptions
  • Optimized visual assets
📝

Accessible Forms

All platform forms feature clearly associated labels, easy instructions, required field indicators, and helpful validation feedback.

  • No placeholder-only labels
  • Clear error messaging with icons
📱

Responsive Accessibility

Fully responsive layout optimized across mobile phones, laptops, desktops, and tablets without forcing horizontal scrolling.

  • Proper scaling & touch targets
  • Usable mobile navigation

📝 Text & Readability

DARAWAT uses readable font sizes, maintained spacing, structured headings, and bulleted lists to prevent unnecessary visual complexity.

Users should be able to understand important information without unnecessary visual complexity.

📱 Responsive & Device Adaptability

Accessibility applies to every screen size. Our interface adapts dynamically across mobile devices, tablets, and desktops, ensuring buttons and forms remain fully operable.

Accessibility is not limited to desktop computer users.

🗺️ Map & Location Accessibility

While interactive maps are useful for discovering nearby producers in San Jose de Buenavista, location is never the sole way to access information.

We provide clear text details including producer names, barangays, general locations, and addresses. Precise location sharing is never strictly required unless a feature genuinely demands it.

🔎 Accessible Search & Discovery

Product discovery is built with clear search labels, useful error notices, and keyboard-friendly filter controls.

If no results match your query, our system clearly states: “No products found. Try a different search term or browse another category.” rather than showing a blank page.

💬 Accessible Communication

We use descriptive action labels throughout the website instead of vague phrases.

  • Use Contact Producer instead of "Click Here"
  • Use Send Message instead of "Submit"

🗣️ Simple Language & Content

Designed for our local community in Antique, we use simple language, short sentences, familiar terms, and clear headings without unnecessary technical jargon.

🎨 Accessible Colors & Error States

Our color palette maintains strong contrast. Crucially, errors and success notifications never rely on color alone.

  • Error states include ❌ icon + descriptive text
  • Success alerts include ✓ icon + descriptive text

🌾👤 For Producers & Consumers

Whether setting up a producer profile, uploading product listings, searching categories, or contacting local farms, all core tools are designed free of unnecessary technical barriers.

Quick Accessibility Tips

Helpful shortcuts for navigating DARAWAT based on your device or assistive tool.

Keyboard Users

Use Tab to move between controls and Enter / Space to activate buttons.

Screen Reader Users

Use standard headings and semantic landmarks to navigate content efficiently.

Mobile Users

Utilize built-in mobile browser zoom and device accessibility settings when needed.

Low-Vision Users

Use the DARAWAT text-size buttons (A−, A, A+) and High Contrast toggle above.
